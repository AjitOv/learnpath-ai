## 💡 The Core Problem & AI Solution

Traditional education platforms give every student the same curriculum and treat incorrect answers as a binary `0/1`. 

**LearnPath AI asks:**
> **"Why did the student get it wrong?"**

By capturing cognitive telemetry (response timing, self-reported confidence, and distractor patterns), LearnPath AI pinpoints the **root misconception** (e.g. confusing denominators with integers, or getting calculations right but struggling with semantic word-problem representations). It then dynamically adapts what the student learns next in real time.

```
Diagnose ➔ Identify Root Misconception ➔ Socratic Teach ➔ Adaptive Practice ➔ 4-Factor Calibration ➔ Adapt ➔ Master
```

## 🧠 Signature Intellectual Property

### 1. The Learning Graph™
An interactive neural knowledge representation:
* Visual connected nodes: **Algebra Foundations** (91% 🟢) ↔ **Fractions** (82% 🟢) ↔ **Decimals** (71% 🟡) ↔ **Applied Word Problems** (54% 🔴).
* Luminous neural branches and interactive inspection drawers.
* 4-Dimension breakdown: **Understanding**, **Application**, **Accuracy**, and **Retention**.

### 2. Student AI Command Center
* **Today's Focus:** Large radial circular mastery gauge with instant learning action.
* **AI Coach Insight:** Explains cognitive patterns with interactive *"Show me why →"* reasoning.
* **Calibrated Progress:** 4-factor non-judgmental mastery meters.

### 3. Cinematic AI Teaching Mode
* Centered conceptual proof canvas (*"WHY DOES 0.5 = 1/2?"*).
* Interactive **visual fraction slider** (`0.25 = 1/4`, `0.50 = 1/2`, `0.75 = 3/4`, `1.00 = Whole`).
* Multilingual voice synthesis (English, Hindi, Marathi).

### 4. Smart 2-Mistake Interception
* Adaptive practice engine halts question spam after 2 consecutive errors on the same pattern, triggering an AI micro-scaffold rule before resuming.

### 5. Educator Radar & Parent Story Portal
* **Teacher Mode:** Highlights class misconception clusters (e.g. 8 students struggling with fractions) with 1-click targeted assignments.
* **Parent Mode:** Simple weekly growth story (+14% progress) with low-friction dinner conversation starters.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/AjitOv/learnpath-ai.git

# Navigate into project directory
cd learnpath-ai

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

---

## 📦 Production Build

```bash
npm run build
```
Creates an optimized production bundle in `dist/` in ~350ms.
